How to Install Dev-C++

Follow these simple steps to install Dev-C++ on your Windows PC for C and C++ programming.

Step 1: Download the Setup

Click the "Download Setup" button on the previous page. Ye aapko SourceForge par le jayega. Wahan se setup file download ho jayegi.

Step 2: Run the Installer

Download hone ke baad, setup file par double-click karein. Windows aapse permission maangega, usko "Yes" karein.

Step 3: Choose Language

Installer khulne par aapse language select karne ko kaha jayega. "English" select karein aur "OK" par click karein.

Step 4: Accept the Agreement

License agreement ko parh kar "I Agree" par click karein.

Step 5: Choose Components

Default components ko waisa hi rehne dein aur "Next" par click karein.

Step 6: Choose Install Location

Default folder (C:\Program Files (x86)\Dev-Cpp) theek hai. Bas "Install" par click karein.

Step 7: Finish Installation

Jab installation complete ho jaye, toh "Finish" par click karein. Agar "Run Dev-C++" par tick hai, toh software turant khul jayega.
