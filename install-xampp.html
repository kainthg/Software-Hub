How to Install XAMPP

Follow these steps to install XAMPP (Apache, MySQL, PHP) on your Windows PC.

Step 1: Download XAMPP

Go to the Apache Friends website and download the latest version of XAMPP for Windows.

Step 2: Run the Installer

Double-click the downloaded .exe file. If Windows Defender or antivirus pops up, click "Yes" to allow it.

Step 3: Select Components

You will see a list of components (Apache, MySQL, FileZilla, etc.). Keep them all checked and click "Next".

Step 4: Choose Install Location

By default, it installs to C:\xampp. It is recommended to keep it as it is. Click "Next".

Step 5: Language Selection

Choose English (or your preferred language) and click "Next".

Step 6: Complete Installation

Click "Next" and wait for the installation to finish. Once done, click "Finish" to open the XAMPP Control Panel.

Step 7: Start Apache and MySQL

In the XAMPP Control Panel, click the "Start" buttons next to Apache and MySQL. If they turn green, everything is working!
