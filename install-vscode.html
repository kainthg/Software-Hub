How to Install Visual Studio Code

Follow these simple steps to install VS Code on your Windows PC.

Step 1: Download the Installer

Click the "Download Setup" button on the previous page to download the .exe file. Once downloaded, double-click it to start the process.

Step 2: Accept the Agreement

Read the license agreement and select "I accept the agreement". Then click Next.

Step 3: Choose Destination

Leave the default installation folder as it is, or choose a new one, and click Next.

Step 4: Start Menu Folder

Keep the default name for the Start Menu folder and click Next.

Step 5: Additional Tasks (Important)

Make sure to check the box that says "Add to PATH" and "Create a desktop icon" if you want one. Then click Next.

Step 6: Install

Click the "Install" button and wait for the process to finish. It usually takes a few seconds.

Step 7: Finish

Make sure "Launch Visual Studio Code" is checked and click Finish. You are ready to code!
