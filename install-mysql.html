How to Install MySQL

Follow these steps to install MySQL Server and Workbench on your Windows PC.

Step 1: Download the Installer

Go to the official MySQL download page and download the "MySQL Installer for Windows" (MSI Installer).

Step 2: Run the Installer

Double-click the downloaded file. Accept the license agreement and click "Next".

Step 3: Choose Setup Type

Select "Developer Default" for a complete installation (includes Server, Workbench, and Connectors) or "Custom" to choose manually. Click "Next".

Step 4: Install Requirements

The installer might ask you to install some required software (like Visual C++ Redistributable). Click "Execute" and then "Next".

Step 5: MySQL Server Configuration

Choose "Standalone MySQL Server / Classic MySQL Replication". Keep the default port (3306) and authentication method, then set a Root Password. (Remember this password, you will need it later!)

Step 6: Finish Installation

Click "Execute" to install all components. Once done, click "Finish". You can now open MySQL Workbench from your Start Menu.
